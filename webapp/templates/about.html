About DeepDefend NIDS

Production-grade Network Intrusion Detection System for imbalanced enterprise networks

Architecture
Three-Layer Cascaded Detection:
  1. Anomaly Detection (Isolation Forest) - Filters normal traffic
  2. Attack Classification (XGBoost Ensemble) - Identifies attack type
  3. Probability Calibration (Platt Scaling) - Trustworthy confidence scores

Dual Detection Sources:
  • Snort IDS - Signature-based known attack detection
  • ML Engine - Behavioral anomaly detection for zero-day attacks
Attack Classes Detected
DoSDenial of Service attacks (SYN flood, Smurf, etc.)
ProbeNetwork reconnaissance and port scanning
R2LRemote-to-Local unauthorized access attempts
U2RUser-to-Root privilege escalation (0.04% of data)

Key Innovation: Handles extreme class imbalance where U2R attacks represent only 52 out of 125,000 training samples (0.04%).
